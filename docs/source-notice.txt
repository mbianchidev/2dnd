Corresponding source, dependency lockfile and build instructions:
https://github.com/mbianchidev/2dnd

Use the source commit identified by the distributor's build receipt, not a
later main branch or a different release. A public distributor must make that
exact corresponding source and its build scripts available with the binary.
Desktop packaging adds the immutable source URL before any code signing.

Build prerequisites: Node.js 24 and npm. From the matching source checkout:
  npm ci
  npm run build:desktop
  npm run generate:desktop-icons
  npm run package:steam:ci -- <platform and architecture arguments>
